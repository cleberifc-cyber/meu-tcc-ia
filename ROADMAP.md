# Roadmap

## Alpha delivered in this branch

- Local guided project scaffold, staged prompt-only workflow, DOI metadata retrieval, citation checks and DOCX preview export.

## Next, gated on evidence

- Broader DOCX structures and citation/reference formatting fixtures.
- Accessible source-confirmed normative edition tracking and institution-specific profiles.
- Optional PDF conversion with locally installed LibreOffice.
- More DOI edge-case handling, user correction commands and public API integration tests that remain opt-in.
- English onboarding and recorded demo after the CLI contract stabilizes.

Items are plans, not delivery guarantees. A verified ABNT profile requires authorized access to and review of exact applicable editions.
