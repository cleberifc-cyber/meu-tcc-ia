# Seu projeto de TCC

- `tcc.toml`: dados iniciais e perfil de formatação selecionado.
- `tcc.md`: manuscrito de trabalho; substitua os comentários com seu conteúdo e evidências.
- `references.json`: registro local de metadados bibliográficos.

O modo padrão é local. Prompts são apenas instruções para a ferramenta de IA que você escolher; revise o texto, confira as fontes e siga as orientações de sua instituição.
