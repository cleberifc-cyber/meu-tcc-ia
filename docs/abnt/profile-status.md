O perfil não inclui texto protegido das normas. Passar a `verified` exige identificar edições exatas em fonte autorizada, revisar regras e exemplos originais, cobrir cada recurso anunciado em testes e registrar revisão/data. Até esse gate ser cumprido, cada exportação alerta que é apenas uma prévia.
